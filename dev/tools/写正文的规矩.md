# 喵站 · 写课程正文的硬规矩

给站内任何一门课写正文之前，先把这份读完。每条都有机器检查或明确理由，不是建议。

## 产出形态

每课**单独一个文件**，放在 `dev/frontend/assets/data/ms/<课程>-c<NN>.js`（Python 课走另一套，见 `dev/frontend/assets/data/py/p*.js`）：

```js
window.MIAO_MS_BODY = window.MIAO_MS_BODY || {};
window.MIAO_MS_BODY["ml-c03"] = [
  { t: `tip`, color: `blue`, text: `本课目标：……` },
  { t: `h2`, text: `原理讲解` },
  { t: `p`, text: `……` },
  { t: `svg`, code: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 240">…</svg>`, caption: `一句话说明这张图在看什么` },
  { t: `code`, lang: `python`, code: `……` },
  { t: `h2`, text: `常见坑` },
  { t: `ul`, items: [`……`, `……`] },
  { t: `h2`, text: `任务` },
  { t: `ul`, items: [`……`, `……`, `……`] },
  { t: `tip`, color: `green`, text: `本课一句话：……` }
];
```

**一课一文件，写完一课就存一课**。不要攒着最后一次写完 —— 有任务中途断过，攒着的代价是全部丢掉。

## 结构（六栏，顺序固定）

`h2 原理讲解` → `h2 假设它能干什么` → `h2 演示 N · 小标题`（2–4 个）→ `h2 常见坑` → `h2 任务` → 结尾一句话 tip。
开头可以有一个 `tip`（`color: blue`）写本课目标；结尾那个 `tip` 必须 `color: green`。

## 篇幅上限（超了就是不合格）

- 每章 **≤25 块**
- **正文 ≤1,800 字**（只算 `p`/`h2`/`tip`/`ul`，不含 `code` 与 `svg`）
- 单段 `code` **≤12 行**
- 宁可少讲一层，不要堆长

## 块类型只有这些

`p` / `h2` / `tip`（color 只取 `blue` `green` `amber` `""`）/ `ul`（`items` 是字符串数组）/ `code`（`lang` + `code`）/ `svg`（`code` + 可选 `caption`）。

## 字符串与转义（最容易翻车的一条）

**文件里字符串的分隔符就是反引号，所以内容里绝对不许再出现反引号，也不许出现 `${`。**
要标代码名就裸写（`print`、`DataFrame`），或者用「」。行内标记渲染层只认 `**加粗**` 这一种。

## 图形化演示

每课**至少一个** `t: 'svg'` 块。画的是**机制**，不是装饰：数据往哪流、两步差别在哪、循环转了几圈。
`viewBox` 用 `0 0 640 <200~320>`；文字用 `<text>`，字号 ≥14，中文；**不要 `<script>`、不要 `onclick`/`href`/`xlink:href`/`src` 属性、不要 `<animate>`**（渲染层会剥掉，写了等于没写，还会让图缺东西）。

## 语言与口吻

- 讲机制，不讲口号。「这个框架很好用」这种句子一律不要，要写它一轮里到底发生了什么。
- **「椰子蛋」「管理」0 次**（作者早年的梗，本轮明确要求清零）。
- 句尾语气词式的「…喵」**0 次**。站名叫「喵站」可以出现在文件头注释里，正文不要。
- 不要「本节将介绍」「让我们来看看」这种文档腔。
- 有立场的吐槽可以留，但要用在能说明问题的地方。

## 交叉引用

只许**往回指**：`ml-c07` 里可以提「第 3 课」「上一课」，**不许出现指向大于本课课号的引用**。
指向后面内容的说法改成「后面单独一课讲它」或者干脆删掉。

## 任务只出题

`h2 任务` 下的 `ul` 至少 3 条，**只出题不给答案**，也不给提示里的代码。要提示就指回本课某个演示。

## 搬外部内容时的授权

- **出处块不要自己写**：数组第一块里不要出现「译自 / MIT」，挂载层会自动补。
- 原文里的图片、视频、Discord、问卷、上/下一课导航、smoke-test 链接**一律不搬**。
- 只搬**这一门课允许搬的**（微软 For Beginners 系列是 MIT，可以翻译再发布）。带 NC 条款的（Khan Academy、MIT OCW、CS50、Full Stack Open、Google MLCC）不搬 —— 站上有赞助入口。

## 英语入门（200 词）那一门不一样

它不是一课一个文件，而是**原稿 → 生成物**：

- 手填处只有 `dev/tools/enword/l01-l05.js`、`l06-l10.js`、`l11-l15.js`、`l16-l20.js`、`l21.js`（词表 + 讲解）。
- `frontend/assets/data/enwords-data.js` 与 `enword-exam-data.js` 是 `node dev/tools/enword-gen.js` 的产物，**手改会被下一次重跑冲掉**。
- 改完跑 `node dev/tools/enword-gen.js --check`（只体检不落盘）。它会拦：单词重复、音标出现站内 48 表之外的符号、
  多音节词缺主重音号、缺音频文件、块数 >25、正文 >1,800 字、禁词、指向后面课号的引用、
  **以及「本课目标 / 任务 / 本课一句话」里出现还没教过的英文单词**（讲解与短语里的那些只软报，不拦）。
- 音频不在正文里改：`node dev/tools/enword-words.js` → `enword-tts.py`（幂等，已有的跳过）→ `enword-asr-check.py` 复核。

## 不许碰

`ms-data.js`、`index.html`、`site.js`、`assets/data/index.js`（生成物）、`py/` 下的 Python 正文、
别人的正文文件、`dev/任务书.md`、`enwords-data.js` / `enword-exam-data.js`（生成物）。
不要跑 `bash dev/tests/run.sh`（全量回归由主控跑）。
`ms-gen.js` 与 `sync-body-tags.js` 现在都只调 `gen-index.js`，**不再写 `index.html`** ——
谁把正文脚本写回 `index.html`，首屏就从 120 KB 退回 3 MB，`ui-e2e.js` 的请求账断言会当场红。

## 自查（交付前必须真跑）

```bash
node --check dev/frontend/assets/data/ms/<课程>-c<NN>.js     # 每个文件都要过
```

再自己核：块数 ≤25、正文 ≤1,800 字、单段代码 ≤12 行、内容里 0 个反引号、0 个 `${`、每课有 `svg`、没有指向后面课号的引用。

**没跑过的不准说通过。** 抓取失败、篇幅超标、漏了图，都请直说。
