候选说明
候选一 · 官方双色（修复版）就是现在这张，但把蛇身上的深色划痕和裂口消掉了：平涂官方色、底纹让开标志区、同色描边吃缝。最保守的一版。
候选二 · 只有提示符（不画标志）深底 + 一个巨大的 >>> 。最有「这是一门课」的辨识度，完全不依赖官方 logo，也不会跟主题打架（它本来就是一块深底海报）。
候选三 · 双抱扣（自绘几何，不碰官方 path）把官方轮廓抽成两个一模一样的 L 形抱扣、绕中心转 180°咬合，蓝黄各一枚，头上一个眼孔。全是矩形与圆，尺寸能验算，不存在画歪的空间。
候选四 · 缩进阶梯不画蛇也不画 logo，画的是 Python 真正的招牌：四行代码按缩进一级级右移，条子从蓝走到黄。小尺寸下也能一眼认出是「代码」。
候选五 · 官方双色 · 深藏青牌还是官方那两条蛇，但整张换成深藏青海报，蓝提亮一档才不隐形。深色模式下它是一块深色而不是亮片，浅/粉模式下也站得住。

选定之后：node dev/tools/covers.js --write <v1…v5>，直接把那张写进 assets/img/covers/python.svg。
