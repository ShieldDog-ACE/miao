## 1. V1 目标

交付**可在浏览器直接打开的前台 UI 原型**，验证任务书中的核心浏览闭环与视觉规范：

- 双主题（深色 / 浅色）与设置切换入口完整落地。
- 游客可完整走通：首页 → 分类 → 教程封面 → 章节阅读 → 搜索，全程不强制登录。
- 登录 / 注册（含「跳过」）、个人中心、老师申请、创作中心入口以原型形态呈现。
- 后台管理系统提供一个演示级入口（登录 + 审核队列），验证两端模块边界。

**V1 不做**：真实后端与数据库、真实邮件验证码、Vue 工程化（M1 再迁）。所有数据为内置演示数据，状态存 localStorage。

## 2. 设计规范

### 2.1 主题系统（本版核心要求）

| 令牌 | 浅色模式（白 · 淡粉） | 深色模式（黑 · 粉） |
| --- | --- | --- |
| 页面底色 `--bg` | `#ffffff` | `#0a0a0a`（深夜黑） |
| 浅底区块 `--bg-soft` | `#fdf2f6` | `#141414` |
| 卡片 `--panel` | `#ffffff` | `#1e1e1e`（玄青） |
| 边框 `--border` | `#f5d3dd` | `#333333`（缁色） |
| 正文 `--text` | `#333333`（缁色） | `#ededf0` |
| 次要文字 `--text-2` | `#75757e` | `#9d9da8` |
| 主色 `--accent` | `#fb7da8`（蔷薇粉） | `#fb7da8`（蔷薇粉） |
| 主色强调 `--accent-2` | `#e85b8c` | `#ffb7c5`（朝霞粉） |
| 主色浅底 `--accent-soft` | `#fde8f0` | 粉 15% 透明 |
| 完成态 `--green` | `#2fbf71` | `#3ecf8e` |

> 色板来源：主管提供的 6 张参考图 —— 深夜黑 #0A0A0A / 朝霞粉 #FFB7C5 / 粉雾 #F4C2CD / 木槿粉 #FF9EC8 / 墨色 #3D3D3D / 蔷薇粉 #FB7DA8 / 黛色 #4A4A4A / 缁色 #333333 / 妃色 #F4A7B9 / 芍药粉 #F8B5D0 / 玄青 #1E1E1E。

- 实现：`data-theme` 挂在 `<html>`，全部颜色走 CSS 变量，切换瞬时无刷新。
- 持久化：选择写入 localStorage，下次打开自动恢复；未选择时跟随系统偏好。
- **切换入口（硬性布局要求）**：右上角 **齿轮 ⚙ 设置图标在左、用户头像在右**；齿轮下拉内提供「浅色 / 深色 / 跟随系统」分段切换，并可进入完整设置页。

### 2.2 字体与排版（DeepSeek 网页版对话 UI 风格）

- 字栈：`Inter / PingFang SC / HarmonyOS Sans SC / Microsoft YaHei / Noto Sans SC`，等宽用 `JetBrains Mono / Consolas`。
- 基准字号 15px、行高 1.75，正文宽限 720px 保证阅读行长舒适。
- 大量留白、低存在感边框（1px 浅粉/深灰）、圆角卡片（10–14px）、柔和投影；整体观感对齐 DeepSeek 网页版的干净、通透、对话式排版。

### 2.3 组件清单（V1）

按钮（主/浅/幽）、输入框、验证码行、标签 Chip、教程卡片、目录树、大纲锚点、代码块（含一键复制）、下拉菜单、Toast、Tabs、进度条、弹层（登录引导）。

## 5. 验收点

1. 浅色「白·淡粉」/ 深色「黑·粉」两套主题全页面无撞色、无未着色黑块；选择可记忆。
2. 齿轮恒在头像左侧，两处（下拉 / 设置页）均可切主题。
3. 游客从首页到读完一章全程无登录墙；收藏等受限动作弹「去登录 / 暂不登录」。
4. 阅读页目录树高亮当前章、标记完成后打勾，教程页可「继续学习」。
5. 搜索三 Tab 有结果 / 无结果两种状态。
6. 后台演示可登录并通过 / 驳回队列条目，有 Toast 反馈。
