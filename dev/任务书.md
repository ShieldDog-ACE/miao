## 1. 需求原文（硬约束，只能补充不能覆盖）

1. Python 教程的**第 0 课不变**（= `s01`/`s02`/`s03` 三节准备课，保留原来的「完成！」按钮）。
2. 从**第 1 课**开始，课末的「完成」**替换为「进入考试」**；**只有考试通过才能标记完成**。
3. 进入考试会给一个任务，例如「打印 hello world」。
4. 觉得难可以**左上角直接退出**。
5. 考试要**内置代码编辑器和终端**，编辑器与终端的页面**全部参考 VS Code**，终端布局也参考 VS Code（**屏幕正下方**）。
6. **任务目标不能太严格**，大概意思对即可 —— 不能因为多打一个空格就判错。
7. 后面的 if 等语句，要**检测它实际经过了什么**，符合任务目标就算通过。
8. 英语那里**同理**。
9. 从第一节课开始**每一课都考试**。
10. 英语第一、二节的考试标准（他给定）：**≥60 分通过**；**10 道选择题**；**5 道听力选出字母**；**5 道听力写出字母**；**4 对 4 勾线题 5 题**。
11. 想加更多题由我主导，但**要跟他说一声**；**分数指标由我定**。

| `super().__init__` 报「object 没有 __init__」 | `methodOf` 不认识 super 代理对象，落回 `typeName` 得到 'object' | `methodOf` 对 `k==='super'` 直接走 `attrGet` |
| `isinstance(True, int)`、`type(x) is int` 判错 | 名字 `int/str/list…` 绑的是普通函数，不是 type 对象 | 把类型名改绑成 PyType 对象，构造函数挂在 `PyType.ctor` 上（类型本来就是可调用对象） |
| `True + True` 报错、`f'{True}'` 打成 1 | 我把 bool 排除在 `isNum` 之外 | `isNum` 收进 bool（bool 是 int 的儿子），格式化时再单独按 `True/False` 排 |
| 写文件后没 close 就能读到内容 | 我每次 write 立刻落盘 | 改成缓冲到 flush/close，第 42 课那句演示才有真依据 |
| KeyError 打印成 `"\"'王五'\""` | 构造异常时先把 key repr 了一遍，`str()` 又 repr 一遍 | 只传原始 key，交给 `excStr` 统一按 Python 规矩加引号 |
| 多继承 `__mro__` 顺序不对 | 我用的是深度优先 | 换 C3 线性化（含冲突时保守取头，保证不死循环） |
| 中文变量名 262 行全炸 | 词法只认 ASCII 字母 | 名字用 `\p{L}` 类匹配，CJK 标识符正常解析 |

**沙箱自身的取舍（写在明面上）**
- 内存地址是假的：`<function x at 0x…>` 与 `id()` 都给确定性的假地址，测试里把 `0x[0-9a-f]{6,}` 抹平成 `0xADDR` 再比。
- `sys.getsizeof`、`random.*`、`compile()` 内部信息这类段落归 loose 桶：只要求沙箱跑完且退出码与 CPython 相同，不比 stdout。
- 不支持生成器 `yield`、`async`、`match`（正文 433 段里一次都没出现）；遇到就明说「本沙箱不支持」，不静默错判。

## 12.6 这一轮的踩坑（现象 → 根因 → 修法 → 下次怎么避免）

| 现象 | 根因 | 修法 | 下次怎么避免 |
| --- | --- | --- | --- |
| 他自己的主音色「鸿纱由美」读英文 8/8 全挂 | 中文音色零样本迁移英文会串语种（apple→「あ」、school→「救う」），跟音量、响度都无关 | 换成 ASR 命中率当第一判据，再配「词长随音节伸缩」的相关性做第二判据 | 选音色不能靠耳朵印象，先跑 8 词 × N 音色的转写对拍 |
| 一批短词听着缺起头（shirt→「her」、tea→「ea」） | 裁静音阈值取峰值 2%，清辅音 /ʃ/ /t/ 的能量本来就低于这个门限，被当静音裁了 | 阈值降到 0.8%，head/tail pad 提到 0.10 / 0.20 s | 音频后处理的阈值要拿「最轻的那个音素」当样本验，不能拿峰值比例想当然 |
| `tea` 六个语速全部只听到「t」，同一条音频改一下头部静音就在 tea / t / qi 之间跳 | ASR 在 1 秒级孤立短词上本来就不稳，跟读得对不对无关 | 单独归档成「要人耳过一遍」，不混进「需重做」名单 | 自动闸要能区分「东西坏了」和「量具不够准」，后者不许算失败 |
| 进 Python 考场报 `ReferenceError: require is not defined` | UMD 头写成 `root.MIAO_PYRUN \|\| require("./py-stdlib.js")`：site.js 里 `engines.code` 把 exam-grade 排在 py-* 前面，全局名还没到位就去走 require 分支 | 顺序改成 py-* 在前；四个 UMD 文件都加 `typeof require === "function"` 保护；data.js 装配失败时点名报错 | 「加载顺序无所谓」是静态站最贵的错觉，凡是靠全局名接力的脚本，顺序就是一份接口契约 |
