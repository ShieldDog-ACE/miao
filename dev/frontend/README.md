# 喵站（前台）—— 纯静态站，这里就是全部产物

面向所有用户的**内容展示、阅读与课末考试**入口。需求基准见根目录《SPEC.md》
（§15.9 考试系统、§15.10 去后端、§15.11 英语入门、§15.12 首屏按需加载）；
目录结构、本地预览与「加一门教程」的规矩见 `dev/README.md`。

## 职责范围

- 首页 / 分类页 / 教程详情 / 章节阅读页（三栏布局）/ 搜索
- 列表筛选只换下面的列表：首页教程、视频卡片、考试题目换分类 / 难度时，
  标题和筛选栏节点不重画；视频 / 考试同板块切换与文档左目录一样走交叉虚化
- 导航「考试」：独立算法题库（`#/exams` 列表 + `#/exams/<id>` 做题），13 道 Python 题，
  分类改成题型（数组 / 哈希表 / 栈 / 双指针…），列表一行一题：难度 / 结果在右，最右一颗收藏星；
  做题页是力扣风两栏（左「题目描述」：示例和提示只放文字，不做专属卡片；右代码栏：
  默认 C++（用本地编译器，运行 / 提交会打开 Linux / Windows / macOS 指南并给 main.cpp 下载），
  Python 3 走浏览器内真实沙箱；重置 / 运行·提交一组；题面 / 代码可拖分栏，代码 / 测试面板可拖高度，
  两侧都有全屏（在收起左边）；重置左边的小齿轮打开代码设置：代码字号 + CLion / Trae / VS Code
  三种高光（颜色直接取自本机安装的 CLion Islands Dark / Trae Dark / VS Code Dark Modern 主题）；重置先弹确认层）；测试用例是 Case 标签 + 参数输入，
  测试结果按力扣样张：通过 / 执行用时 + Case 标签 + 输入 / 输出 / 预期结果，不显示内存和「未过」；
  没有通过率、企业标签、打卡与排行榜。判分在 `assets/js/algo-judge.js`，界面在 `algo-ui.js`，题目在 `assets/data/algo-exam-data.js`
- 课末考试：路由仍在（`assets/js/py-*.js`、`exam-*.js`），但文档类教程已经不再挂「进入考试」入口，
  只保留「完成！」；需回课时由直接地址进入。
- 英语两门课：`english`（26 字母 + 48 音标，音频 `assets/audio/letters|phonemes/`，3 场考卷）
  与 `enwords`（英语入门：21 课 257 词，音频 `assets/audio/words/` 257 条，21 场课末卷 + 1 场结课大考）
- Git 入门：`assets/data/git-data.js`，3 章（三个区 / 四种撤回 / 分支合并），没拆片、这一版不排考
- 单词卡：一个词 = 单词 + 词性 + 音标 + 中文 + 常用短语 + 一只播放键，音频**点了才拉**（卡片里没有 `<audio>` 元素）
- 收藏、学习进度、考试成绩 —— 全部只写本机 `localStorage`，没有任何账号与同步
  （算法题库另用 `miao_algo_results` 与 `miao_algo_draft_<id>` 两个前缀）
- 页脚「成为老师」：投稿与纠错只有一个邮箱（`assets/data/site.js` 里的 `contact.email`）

  极淡弥散阴影、胶囊按钮与 0.3s 缓动微交互；miao 的原版规则一行不动。首页是文档式标题 + 分类 /
  难度 + 每行四门的教程栅格；mac 下算法做题页与课末考场也换成圆角卡 / 毛玻璃 / 胶囊按钮。
  mac 深色是 `#141417` 底 + 星空层（两层星点持续闪、蓝白微光）；教程卡 / 视频卡 / 考试行 / 章节目录
  进视口才逐个浮入；跨板块换页淡入上移；**同一板块内切换**（文档左目录 / 视频合集 / 题库列表）
  改成交叉虚化：旧页快照盖住，新页画好后快照淡出，不再逐项浮入或上浮；精致风格下考试进入题目、
  收起 / 全屏都有过渡动画；分类与难度筛选只留文字，
  首页 / 视频 / 考试的标题同一字号。
- **正文 Markdown 渲染层（2026-11-19）**：阅读页现在优先读章节的 `md` 字段；有 `md` 就用
  `MIAO_MD.blocks()` 解析成原来的 p / h2 / ul / ol / code / tip / svg / en / img / audio 块，
  再走原来的 `blockHtml`，格式与旧稿完全一致。方言：`## 标题`、`- / 1. 列表`、三反引号代码、
  `:::tip blue`、`:::svg caption=...`、`:::en kind=ph`、`:::img`、`:::audio`；行内支持
  `**重点**`、`[文字](https://…)`、反引号代码。**旧 .js 正文没有迁移**，没有 `md` 的章节继续走
  `blocks`；本轮只加渲染层，后续再把 `.md` 源编译/嵌入到 `md` 字段。
- **导航「考试」上线**（2026-11-11）：独立的算法题库 `#/exams`（13 道 Python 题，分类 / 难度筛选、
  已通过标记）与 `#/exams/<id>` 做题页。做题页在 2026-11-12 按用户给的力扣截图重做：
  左「题目描述」（示例和提示纯文字）/ 右代码栏（顶栏右上角 重置·运行·提交、全屏、折叠），
  屏幕下方「测试用例 / 测试结果」两个页签；测试用例是 Case 标签 + 参数输入，结果为通过 / 用时 +
  输入 / 输出 / 预期结果；编译失败只显示报错。
  它按需加载 `algo-exam-data.js` / `algo-judge.js` / `algo-ui.js` 与 Python 沙箱，首屏仍是 5 份脚本；
  没有通过率、企业标签、打卡、排行榜，也没有「题解 / 提交记录」假页签。
- **没有后端**：`dev/backend/` 已整体删除；正文、题库、音频都是本目录下的静态文件，
  由 `assets/js/data.js` 这个本地数据层组装成 `MIAO_DATA` 与同名同形的 `MIAO_API`。
  页面上出现任何 `/api` 请求都算回归失败（`dev/tests/ui-e2e.js` 有这条断言）。
- **分层加载改到章级**（2026-10-13，《SPEC.md》§15.13）：首屏只拉 5 份脚本（180 KB / gzip 59 KB）；
  点进一门课只注入它的**骨架 `boot`**（3–63 KB，详情页的章节目录靠 `index.js` 里的章号与标题）；
  点开哪一章才拉**那一章的分片**（`chunks`：由生成器单跑每份正文、按「后写的顶掉先写的」算出来的赢家）；
  这一章落到页面后，读者没别的事时空闲按「离当前章就近」一片一片补齐同门其余分片，读者一动就收手。
  考场脚本与题库进考场才注入，进考场同样不为考试拖来整门课正文。没点开的课零请求。
  旧的「每窗 2000 字 + 继续加载」按钮仍然取消 —— 静态站里那只是障眼法，正文本来就在本地。
- 目录 `assets/data/index.js` 是**生成物**（`node dev/tools/gen-index.js`）；改了章标题、章数、词表
  或正文分片的归属都必须重跑，否则目录和正文会说两套话（生成器现在就当场验这四条：只拉 boot 拿得到包、
  装配函数可重入、每章都有出处文件、每份分片都顶着一章）。`index.html` 里出现正文 `<script>` 就算破功，
  `ui-e2e.js` 的请求账断言（首屏 5 份 + §7.9 那 12 条分层账）盯着。
- 代价写在明面上：静态文件整包可下载，收藏与进度换设备即归零，判分在前端可被绕。见《SPEC.md》§15.10。
