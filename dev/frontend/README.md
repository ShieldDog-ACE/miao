# 喵站（前台）—— 纯静态站，这里就是全部产物

面向所有用户的**内容展示、阅读与课末考试**入口。需求基准见根目录《SPEC.md》
（§15.9 考试系统、§15.10 去后端、§15.11 英语入门、§15.12 首屏按需加载）；
目录结构、本地预览与「加一门教程」的规矩见 `dev/README.md`。

## 职责范围

- 首页 / 分类页 / 教程详情 / 章节阅读页（三栏布局）/ 搜索
- 课末考试：浏览器内置 Python 沙箱 + VS Code 风格考场 + 判分器（`assets/js/py-*.js`、`exam-*.js`）
- 英语两门课：`english`（26 字母 + 48 音标，音频 `assets/audio/letters|phonemes/`，3 场考卷）
  与 `enwords`（英语入门：20 课 200 词，音频 `assets/audio/words/` 200 条，20 场课末卷 + 1 场结课大考）
- 单词卡：一个词 = 单词 + 词性 + 音标 + 中文 + 常用短语 + 一只播放键，音频**点了才拉**（卡片里没有 `<audio>` 元素）
- 收藏、学习进度、考试成绩 —— 全部只写本机 `localStorage`，没有任何账号与同步
- 页脚「成为老师」：投稿与纠错只有一个邮箱（`assets/data/site.js` 里的 `contact.email`）

## 状态（2026-10-06 起）

- **没有后端**：`dev/backend/` 已整体删除；正文、题库、音频都是本目录下的静态文件，
  由 `assets/js/data.js` 这个本地数据层组装成 `MIAO_DATA` 与同名同形的 `MIAO_API`。
  页面上出现任何 `/api` 请求都算回归失败（`dev/tests/ui-e2e.js` 有这条断言）。
- **分层加载改到章级**（2026-10-13，《SPEC.md》§15.13）：首屏只拉 5 份脚本（176 KB / gzip 57 KB）；
  点进一门课只注入它的**骨架 `boot`**（3–63 KB，详情页的章节目录靠 `index.js` 里的章号与标题）；
  点开哪一章才拉**那一章的分片**（`chunks`：由生成器单跑每份正文、按「后写的顶掉先写的」算出来的赢家）；
  这一章落到页面后，读者没别的事时空闲按「离当前章就近」一片一片补齐同门其余分片，读者一动就收手。
  考场脚本与题库进考场才注入，进考场同样不为考试拖来整门课正文。没点开的课零请求。
  旧的「每窗 2000 字 + 继续加载」按钮仍然取消 —— 静态站里那只是障眼法，正文本来就在本地。
- 目录 `assets/data/index.js` 是**生成物**（`node dev/tools/gen-index.js`）；改了章标题、章数、词表
  或正文分片的归属都必须重跑，否则目录和正文会说两套话（生成器现在就当场验这四条：只拉 boot 拿得到包、
  装配函数可重入、每章都有出处文件、每份分片都顶着一章）。`index.html` 里出现正文 `<script>` 就算破功，
  `ui-e2e.js` 的请求账断言（首屏 5 份 + §7.9 那 12 条分层账）盯着。
- 代价写在明面上：静态文件整包可下载，收藏与进度换设备即归零，判分在前端可被绕。见《SPEC.md》§15.10。

- `covers/python.svg` 左侧图形是 **Python 官方 logo**：© Python Software Foundation，
  取自 `python.org/static/community_logos/python-logo-generic.svg`，该文件按 CC-BY 3.0 提供。
  这里仅用于指代 Python 这门语言，**不代表 PSF 出品或背书本站**；站点本身与 PSF 无关联。
- `covers/english.svg` 的字母卡、音标芯片与声波均为本站原创几何绘制，无第三方素材。
- `covers/enwords.svg`（英语入门）同族底色、本课主色蓝 `#2f6feb`：单词卡 `apple /ˈæpl/ n. 苹果` +
  12 枚主题芯片 + 读音声波 + 20×10 点阵（点阵用 `<pattern>` 铺死 139×69，画出来就是 200 个点，
  不是「写着 200 其实画了 100」）。全部原创几何，无第三方素材。
