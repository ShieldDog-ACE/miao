# 喵站（前台）—— 开发版核心模块①

面向所有用户的**内容展示与浏览入口**。需求基准见根目录《SPEC.md》第 5、6.1、8.1–8.5 章。

## 职责范围

- 首页 / 分类页 / 教程封面页 / 章节阅读页（三栏布局）/ 搜索
- 邮箱注册登录（允许游客跳过）、右上角个人信息中心
- 我的学习（进度 / 收藏 / 笔记）、消息中心
- 老师申请入口、创作中心（老师）
- 状态：数据全部来自后台管理系统（`/api/*`）；前端静态目录**不含任何教程正文**，
  正文按约 2000 字分窗下发。原 `assets/js/data.js`（全站正文的前端副本）已彻底移除。
